# Code of Conduct

## Our standards

- Be respectful and constructive in all project spaces (issues, PRs, discussions).
- Assume good intent; ask for clarification before criticising.
- Focus feedback on ideas and code, not people.

## Enforcement

Violations can be reported to the maintainer via GitHub Security Advisories (private channel). Reports will be reviewed promptly and handled with discretion.

This project follows the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
